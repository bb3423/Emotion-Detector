# Final Project

## Emotion Detector

This repository contains the *Final Project* for the Emotion Detection application using the Watson NLP library.

The application analyzes text input and detects emotions such as anger, disgust, fear, joy, and sadness. It also identifies the dominant emotion from the analyzed text.

## Features

- Emotion detection using Watson NLP API
- Formatted output with emotion scores
- Dominant emotion identification
- Flask web deployment
- Error handling for blank input
- Unit testing
- Static code analysis

## Project Structure

- EmotionDetection/emotion_detection.py : Application function
- EmotionDetection/_init_.py : Package initializer
- server.py : Flask server
- test_emotion_detection.py : Unit tests
- templates/index.html : Web interface
- static/mywebscript.js : Frontend script

## Technologies Used

- Python
- Flask
- Watson NLP API
- Requests
- Unittest
- Pylint
