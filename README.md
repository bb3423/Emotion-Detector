# Emotion Detector

This project is an AI-based web application that detects emotions from text using the Watson NLP library.

## Features
- Emotion detection using Watson NLP API
- Formatted output with emotion scores
- Flask web deployment
- Error handling for blank input
- Unit testing
- Static code analysis

## Project Structure
- `EmotionDetection/emotion_detection.py`: Application function
- `EmotionDetection/__init__.py`: Package initializer
- `server.py`: Flask server
- `test_emotion_detection.py`: Unit tests
- `templates/index.html`: Web interface
- `static/mywebscript.js`: Frontend script
